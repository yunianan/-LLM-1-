# MentalBench 数据划分与诊断流程评测规范 v2

日期：2026-10-16。适用于整个 L3 诊断流程，包括候选生成、逐候选核对和后续独立验证；数据划分范围不等于某一轮代码修改范围。标准库仍为 DSM-5，系统候选仍为 D001–D023＋Insomnia。

## 第3点 分组与实验含义

保留 KB／DEV／EVAL 三部分和目标比例 5∶2∶3，随机种子为 20261015。KB 用于诊断时的参考示例，DEV 用于修改系统，EVAL 用于冻结后的独立评测。当前系统尚未接入案例检索；划出 KB 不代表接入已经完成。

本版本明确选择**按无序障碍组合留出的严格泛化实验**。同一个单障碍 source_code 或无序障碍对的全部记录只能分配给一个部分。92 个不可分单元为：23 个单障碍组、51 个单方向障碍对组、18 个正反双方向障碍对组。

这项选择考察“未在示例池和开发中出现的鉴别组合”上的表现，不声称只要两个独立病例属于同一疾病或鉴别对就必然发生泄漏。相同病例、生成种子及其改写跨部分是需要避免的来源污染；跨病例复用相同诊断知识本身是案例知识库的预期用途。

`related_case_group` 仅是当前可核验的来源编号关系，不等同于真实患者身份，也不能证明所有生成种子已独立。所有数量分别称为记录数、来源组数、超级组数。来源组数不能直接当成统计学有效样本量。

分配槽位：单障碍 11／5／7；单方向障碍对 24／10／17；双方向障碍对 10／3／5。由固定种子的确定性搜索满足各部分 23 标签覆盖，禁止根据诊断模型表现选择分配。隔离前记录数为 12,375／4,725／7,650；整组约束导致与精确比例有小幅差异。

实现：`tools/mentalbench_partition.py`。

## 第4点 隔离规则与记录归属

先按来源组分配所有记录，再做输入筛查，不把 DEV/EVAL 的坏记录搬进 KB，也不拆散其来源组。每条记录有一个且只有一个分区归属，另有“活动／隔离”状态。总账 = KB活动＋KB隔离＋DEV活动＋DEV隔离＋EVAL活动＋EVAL隔离，必须等于 24,750；各分区活动数不是原始分配数。

规则分为三类：

- **所有部分都隔离**：空占位、过短碎片、英文病例中的中英破损残留。KB 也不允许自动收录这些记录。规则属于可复现的质量筛查，不冒充临床正确性审核；人工确认可读后必须另发新版本才能恢复。
- **仅盲测输入隔离**：正文明确给出当前诊断结论。内容完整时可作为带标签 KB 示例；若已归属 DEV/EVAL，则留在所属分区的隔离区，不能迁移。
- **仅记录待核对标记**：出现病名、既往诊断、否定病史、临床语气，不据此自动认定泄漏。输入中的自然病史事实保持原样，不为匹配规则删除原文。

EVAL 的隔离病例、来源元数据和答案与其 gold 一起封存；不输出所有人可读的完整 EVAL `quarantine.jsonl`。公共报告只含汇总数量和规则，KB/DEV 可见其自己的隔离清单。隔离记录永不进入检索索引或评分输入。

实现：`tools/mentalbench_quality.py`。所有规则在模型评测前固定。

## 第5点 整个 L3 的分阶段指标

`tools/evaluate_candidate_predictions.py` 兼容单独的 candidates 输出和完整 L3 report。单标签参考任务与 Type 3 的 admissible_candidates 分开报告，混合输入不再给出一个可被误读成统一诊断效果的总体 PPV/召回。

- Step 1：严格标注匹配的 micro PPV/召回、Top-K 召回和命中、空候选比例、按标签 precision/recall/F1 和 macro。macro 对有金标准支持的标签求平均；未预测该标签时其 macro precision 取 0。
- Step 2：统计被实际核对的正确候选中有多少被 ruled_out；单独报告分母，缺失核对结果不视为已评测。
- 最终结果：仅对单一参考标签任务报告命中和集合 exact match。Type 3 不作为确诊共病或唯一最终诊断的标准。
- MentalBench 标签覆盖的分母为 23；系统范围仍为 24。Insomnia 没有参考样本，召回为不适用。若模型输出 Insomnia，继续保留在严格标注 PPV 的预测数中，并单独计数，不能静默删掉，也不能据此证明临床上不存在该病。
- 分开报告记录、来源组、超级组数量，不宣称某个数量就是统计有效样本量。严格组外实验以超级组聚类 bootstrap 为主要区间，同时提供来源组聚类敏感性区间；默认 1,000 次，种子 20261015。

所有分数均指相对于数据集参考标签的研究指标；合成数据的标签完整性和临床外部有效性限制仍然存在。
